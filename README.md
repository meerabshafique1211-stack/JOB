# JobsApply

Private AI job-search and recruitment-outreach platform for one user. It finds European remote and visa-sponsored
vacancies, scores them against the master CV with Claude, researches hiring contacts, writes personalized emails, CVs and
cover letters, and sends approved batches through Gmail.

See **[SETUP.md](SETUP.md)** for credentials, deployment and the full workflow.

```bash
cp .env.example .env.local   # fill in values
npm install
npm run dev
```
